# Product

## Register

product

## Users

Linux desktop users who need a fast scientific calculator for everyday math, technical calculations, and natural-language math questions. They use it in a task context: entering expressions, checking intermediate results, reusing history, and optionally asking the local or OpenAI-backed assistant for explanations.

## Product Purpose

Matrix Calculator exists to provide a reliable, local-first scientific calculator with a modern PySide6 interface. Success means users can calculate quickly without account setup, understand results, switch between basic and scientific workflows, and use optional AI help without making the core calculator dependent on online services.

## Brand Personality

Practical, precise, calm. The interface should feel trustworthy and focused, with enough visual identity to be recognizable but no decoration that slows down calculation.

## Anti-references

Avoid novelty calculator skins, terminal cosplay, overloaded AI chat surfaces, marketing-style hero layouts inside the app, and visually noisy scientific panels where every operation competes for attention.

## Design Principles

1. Put calculation first: expression, result, and primary operations must remain visually dominant.
2. Keep advanced features discoverable without making the default state feel heavy.
3. Prefer familiar calculator and desktop conventions over invented controls.
4. Make optional AI feel clearly secondary to local calculation.
5. Use contrast and spacing to support repeated use in long desktop sessions.

## Accessibility & Inclusion

Target WCAG AA contrast for text and controls where Qt styling allows it. Preserve keyboard operation for calculator input, visible focus states, high-contrast theme support, and reduced reliance on color alone for operation categories.
